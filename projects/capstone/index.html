Ultra Modular Systems

Framework for UE5 abilities and stats · C++ and Blueprint · 3 months

'Ultra Modular Systems' was my capstone project: a modular, efficient, and reusable Blueprint framework for UE5, built over 3 months. I was sick of constantly going back to redo core logic in my projects because I hadn't designed things "modularly enough".

So, I created a framework that takes modularity and reusability to their extremes while staying usable and approachable in Blueprint. It combines C++ base classes with a lot of Blueprint to create fully modular abilities, effects, stats and art.

The project consisted extensive research into creating reusable code and how to translate that into UE5 and ideally blueprint, while also keeping it 'user friendly'. Trying to keep in line with these goals also had a ton of development, testing and iteration.

It isn't fully launched yet, but is planned to be by the end of 2026.
